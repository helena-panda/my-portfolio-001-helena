## 1. 单摆 `pendulum.html`

### 物理模型
- 运动方程：`α = -(g/l)·sinθ - γ·ω`（γ 为阻尼系数）
- 欧拉积分，`dt` 自适应钳制；`l = 摆长/100` 将像素换算为米
- 阻尼带增益系数（`DAMPING_GAIN=60`），使 0.010 量级阻尼在数秒内可见衰减

### 功能
- **天体场景一键切换**：地球 9.8 / 月球 1.62 / 火星 3.71 m/s²
- **实时控制面板**：摆长 100~350px、重力 1~25（步长 0.01）、阻尼 0~0.010
- **LocalStorage 持久化**：自动保存摆长 / 重力 / 阻尼 / 当前星球，重开页面自动恢复
- **相图（右侧上板）**：以摆角 θ 为横轴、角速度 ω 为纵轴实时绘制闭合曲线；
  量程按无阻尼理论峰值 `√(2g/l(1-cosθ₀))` ×1.1 自动缩放，无阻尼时曲线严格闭合，有阻尼时螺线衰减趋近原点
- **能量柱状图（右侧下板）**：动能 / 势能 / 总能量三根横向柱，按初始势能 `E₀ = mgl(1-cosθ₀)` 归一化；
  显示实时数值，虚线标尺表示初始能量参考线

### 验证
- 无阻尼 30s 数值仿真：能量漂移仅 ~1.8%
- 重力 / 摆长变更会自动重建能量参考并清空相图，避免跳变

## 2. 双摆 `double-pendulum.html`

### 物理模型
- 双摆拉格朗日运动方程（4 状态变量 `[θ₁, θ₂, ω₁, ω₂]`），标准无量纲方程：
  ```
  θ̈₁ = (-g(2m₁+m₂)sinθ₁ - m₂g sin(θ₁-2θ₂) - 2sinΔ·m₂(ω₂²L₂ + ω₁²L₁cosΔ)) / L₁(2m₁+m₂-m₂cos2Δ)
  θ̈₂ = (2sinΔ(ω₁²L₁(m₁+m₂) + g(m₁+m₂)cosθ₁ + ω₂²L₂m₂cosΔ)) / L₂(2m₁+m₂-m₂cos2Δ)
  ```
- **四阶龙格库塔（RK4）积分**，等效固定步长 1/240s，按真实帧间隔划分子步
- 摆长 75.6px、等质量 m₁=m₂=1、g=980（px/s²，相当于 100px=1m）

### 功能
- **彩虹拖尾**：第二摆球轨迹缓存 90 帧，逐段绘制半透明渐变色相（HSV 流动）+ alpha/线宽双衰减
- **鼠标拖拽**：45px 内拾取最近摆球，拖拽期间冻结物理、直接改写摆角，松手清零角速度、自然释放
- **双击重置**：回到 θ₁=120°、θ₂=160° 高能初始状态

### 验证
- 40 仿真秒（9600 步 RK4）零数值发散
- 能量漂移 0.0005%，角速度峰值 12.66 rad/s，θ₁ 翻转 36 次（确凿的混沌翻转）
- 控制台 0 报错

### 操作提示
拖动任意摆球改变初始角度后松手 → 观察两条摆臂的混沌翻转与彩虹拖尾；
双击画布重置。
