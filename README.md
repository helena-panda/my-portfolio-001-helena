## 仓库简介

本仓库用于归档我在《人机协同备课》课程期间的**全部实验与项目作品**，展示 AI 与人类协同的创作过程与成果。每周实验按周次归档，课程项目统一放在 `project/`，早期实验作品直接存放在根目录。

> 日常操作习惯：每完成一次实验或改动，就进行一次 `commit`；所有作品最终同步（`push`）到本公开仓库，即我的"数字作品集"。

## 使用说明

- **查看作品**：直接点击本仓库中的 `.html` 文件，或复制到本地浏览器打开。
- **每周实验**：进入 `weeks/weekNN/` 查看对应周次的代码与说明。
- **版本管理**：根目录是本仓库的工作区，日常用 `git add`、`git commit`、`git push` 三步完成作品存档。
